# Request

Adopt the text backbone's native full embedding dimension (e.g., 384 for `BAAI/bge-small-en-v1.5`) directly into Belnap Multihead Pooled Attention (MPA), eliminating the intermediate linear adapter bottleneck in `TextEncoder`.

## Reasoning

When `embed_dim` was defaulted to 256, `TextEncoder` inserted an extra `nn.Linear(384, 256)` adapter between the pretrained backbone and `BelnapMultiheadPooledAttention`. However, the MPA already possesses an internal projection (`self.input_proj = nn.Linear(embed_dim, 2 * embed_dim)`) that maps continuous representations into the dual evidence space $(e^+, e^-)$. Stacking an external linear adapter before the MPA is mathematically redundant, introduces a projection bottleneck, and discards fine-grained semantic features present in the full native embedding.
