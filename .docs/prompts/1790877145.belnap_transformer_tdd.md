# Request

Design and specify the Belnap Bilattice Native Transformer architecture (`BelnapAttention`, `BelnapFFN`, `BelnapTransformerBlock`, and `BelnapDecisionTransformer`), write comprehensive unit and property-based test specifications in `tests/test_belnap_transformer.py` (RED phase), create an implementation plan, and delegate implementation to a fast subagent via TDD.

## Reasoning

Standard transformers lack intrinsic four-valued logic capabilities, suffering from attention sink hallucinations under missing information and false compromises under contradictory evidence. A Belnap Bilattice Native Transformer parameterizes hidden states as dual evidence pairs $(e^+, e^-) \in [0, 1]^d \times [0, 1]^d$, with bipolar support/refutation attention modulated by source knowledge $k$. Writing tests first establishes strict behavioral invariants for bilattice arithmetic, attention gating, and uncertainty bounds before code is generated.
