# Request

Implement active-choice logit masking and dynamic candidate epistemic affinity scoring to fully support variable numbers of criteria across the System 1 architecture, training loss, and LTN semantic logic constraints.

## Reasoning

The user noted that a variable number of criteria (candidates) is a foundational requirement for the System 1 decision engine. In the raw dataset, queries contain between 0 and 70+ criteria, with typical choice queries presenting 2 to 5 options. While the data pipeline standardizes batch tensors to a configurable `max_choices` using padding, unmasked logits in softmax and fixed-size universal LTN loss penalize or include non-existent options. Implementing active-criteria logit masking (setting inactive choice logits to $-\infty$ and zeroing inactive truth/knowledge) alongside variable-subset XOR/complementarity logic and dynamic bilinear candidate affinity scoring guarantees mathematical integrity for arbitrary candidate sets.

## Output

- Added `num_active` to `YodaParquetDataset.__getitem__` and `YodaDecisionDataset.__getitem__`.
- Updated `collate_decision_batch` to generate `num_active: torch.Tensor` and boolean `active_mask: torch.Tensor` of shape `(batch_size, max_choices)`.
- Added `ConstraintEncoder.encode_candidates` for dynamic candidate encoding of shape `(batch_size, num_candidates, target_dim)` supporting ragged candidate lists.
- Enhanced `YodaDecisionEngine` to support dynamic candidate affinity scoring (`use_candidate_affinity=True`) and active criteria masking:
  - Inactive logits are masked with `-1e9` for softmax cross-entropy exclusion.
  - Inactive truth, knowledge, choice_pos, and choice_neg are clamped to 0.0 (Belnap ignorance $\bot$).
  - Intermediate DLA probes in `diagnostics` apply active criteria masking with stable finite deltas.
- Refactored `LTNConstraintLoss` to condition universal bivalence and Exactly-One (XOR) semantic losses strictly across active candidate subsets.
- Updated `YodaTrainer` and `YodaLightningAdapter` to pass `active_mask` to model and LTN loss with defensive compatibility fallbacks.
- Authored ADR-0011 (`.docs/adrs/0011-active-criteria-masking-and-candidate-affinity.md`) and indexed in `.docs/adrs/readme.md`.
- Expanded unit test suites in `tests/test_ltn.py`, `tests/test_engine.py`, and `tests/test_training.py` with 100% clean passes across all 97 tests via `just check`.
