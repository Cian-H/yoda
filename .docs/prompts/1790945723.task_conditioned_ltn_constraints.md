## Implementation Plan
- **Dataset (`src/yoda/training/dataset.py`)**: Map `question_type` to a continuous control vector scalar (`"null" -> -1.0`, `"score" -> 0.0`, `"choice" -> 1.0`). Update collation to pass `task_scalars` `(B, 1)`.
- **Architecture (`src/yoda/architecture/engine.py`)**: Add `task_proj = nn.Linear(1, embed_dim)`. In `forward`, project `task_scalars` and add to `q_emb` to condition the epistemic sieve.
- **LTN Loss (`src/yoda/probabilistic/ltn.py`)**: Implement `LTNConstraintLoss(nn.Module)` using differentiable t-norms (Product t-norm: $T(x,y)=xy$) over Belnap states. 
  - Enforce mutual exclusivity for `choice` tasks (penalize $T(truth_i, truth_j)$).
  - Enforce non-contradiction universally (penalize $T(e^+, e^-)$).
- **Trainer (`src/yoda/training/trainer.py`)**: Add `ltn_weight` (default 0.1). Extract `diagnostics` from model forward pass, calculate LTN loss, and add to total loss. Update `train_epoch` and `evaluate` signatures to support `task_scalars`.
