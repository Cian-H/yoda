# Request

Ingest system 1 reasoning datasets starting with Nimble (`bespokelabsai/nimble`) and Kev (`jaredpalmer/kev`), evaluate additional candidates from `awesome-system-one-models`, verify that candidate datasets strictly fit the `DecisionPayload` schema and possess permissive open-source licenses, purge non-compliant datasets, store accepted datasets in `data/`, and aggregate them into a unified dataset for training.

## Reasoning

A System 1 decision engine requires diverse, calibrated decision records pairing rich states/contexts with typed evaluation questions (`choice`, `noul`, `score`) and rule constraints. Ingesting both contrastive synthetic datasets (Nimble) and multi-intent operational datasets (Kev) provides a solid foundation, while strict license screening (e.g. Apache-2.0, MIT vs unstated/restrictive) and schema conformance screening prevent licensing violations and pipeline failures during training.

## Consulted rules

- `.agents/rules/workflow.md` — per-task prompt file, commit discipline, and ADR creation
- `.agents/rules/workflow.md` §2 (ADR) — dataset architecture and schema alignment
- `.agents/rules/workflow-testing.md` — pytest unit testing for data ingestion and normalization pipeline
- `.agents/rules/best-practices.md` — Polars for tabular data and deterministic ordering

## Output

- Screened candidate datasets for license compatibility and schema conformance using TypeSafe Jev verification.
- Audited Kev (`evals/decision-v1` and `evals/decision-v2`) under clean Apache-2.0.
- Audited Nimble (`train.jsonl` / `eval.jsonl`) under research / fair-use posture with explicit provenance tagging for easy retraining.
- Purged non-compliant datasets (`tasksource`, `roskosmos19`, `pngwn`, `FaroukMoc2_image_beans`).
- Transformed and validated records into canonical `DecisionPayload` format.
- Aggregated validated datasets into `data/processed/aggregated_train.jsonl` (9,108 records) and `data/processed/aggregated_eval.jsonl` (2,616 records).
- Authored ADR 0003 documenting dataset ingestion, licensing audit, and schema normalization.
