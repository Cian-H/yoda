# Implement DLA diagnostic probes for YodaDecisionEngine

## Request
"Is there a way we could gain a mechanistic, diagnostic insight into which layers components of the model are managing to successfully learn the representation they need to learn? Maybe something like Direct Logit Attribution (DLA)?"
"Ok. So, now, let's stop and draft a comprehensive design document on how to implement the DLA probes, then dispatch that grunt work of writing the code to a low powered agent."

## Implementation
- Added `return_diagnostics` flag to `YodaDecisionEngine.forward`.
- Spliced intermediate representations `x_0`, `x_1`, `x_2` directly into `self.decision_head` to calculate logits at each step of reasoning.
- Captured logit distributions into `trajectories` alongside `attributions` mapping deltas from post-pooling to post-context to post-constraint stages.
- Included unit tests to verify probe attribution calculation and trajectory structure.
- Removed deferred TODO entry from `.docs/todos/dla-diagnostic-probes.md`.
