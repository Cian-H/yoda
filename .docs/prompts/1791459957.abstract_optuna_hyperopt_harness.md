# Request

Abstract shared Optuna experiment orchestration, study management, subprocess trial execution, and early stopping callbacks from `experiments/optuna_study.py` and `experiments/optuna_study_narrow.py` into a reusable `src/yoda/hyperopt/` submodule (`src/yoda/hyperopt/optuna.py`) to reduce duplication and adhere to DRY principles.

## Reasoning

Both `experiments/optuna_study.py` and `experiments/optuna_study_narrow.py` duplicated subprocess invocation logic, error handling, trial pruning, `history.json` metric extraction, SQLite storage configuration, seed generation, and metadata serialization. Centralizing this execution infrastructure in `src/yoda/hyperopt/optuna.py` keeps experiment scripts lean (focusing purely on parameter search spaces), prevents subtle bugs across sweeps, provides a unified interface for study early stopping, and maintains clean architecture under the `yoda.*` namespace.

## Consulted rules

- `.agents/rules/workflow.md` — task boundary declaration, one prompt file per task, ADR creation for new module, explicit path commit staging
- `.agents/rules/best-practices.md` — Python 3.14 conventions, type hints, structured error handling, test isolation

## Output

- Created `src/yoda/hyperopt/__init__.py` and `src/yoda/hyperopt/optuna.py` providing:
  - `build_training_command`: maps dictionary/typed arguments to CLI flags for `experiments/train_yoda.py`.
  - `run_training_trial`: subprocess execution wrapper with error isolation, pruning handling, and `history.json` metric extraction.
  - `StudyEarlyStoppingCallback`: patience-based early stopping callback for Optuna studies.
  - `init_study_and_metadata`: standardized Optuna study creation with TPE sampler, collision-free seeds, SQLite storage, and metadata JSON dumping.
  - `build_base_study_parser`: shared argparse builder for study scripts.
- Refactored `experiments/optuna_study.py` and `experiments/optuna_study_narrow.py` to use `yoda.hyperopt.optuna`.
- Added ADR `0016-hyperopt-module-and-optuna-harness.md` and updated `.docs/adrs/readme.md`.
- Updated test suite in `tests/test_optuna_study_narrow.py` and added `tests/test_hyperopt.py`.
