# Trial Seed Randomization and Collapse Pruning for Distributed Sweep

## User Request
"For fuck sake. The seed was 42? I explicitly said seeds should be randomised! So then, can we make these changes and continue the same study instead of having to re-do it?"

## Context
1. In the distributed `yoda_focused` sweep across Neon PostgreSQL workers, 26 out of 27 completed trials fell into the identical majority-class basin (eval_accuracy = 0.366875, 587/1600).
2. The root cause was identified: `optuna_study_focused.py` generated a random sampler seed during study initialization, but `objective()` never passed a `seed` key to `params`. Subprocess `experiments/train_yoda.py` defaulted to static `--seed 42` on every single trial. With frozen text backbones and static weights/data shuffling, linear heads consistently initialized into the class-0 attractor.
3. Collapsed trials ran for the full duration (8 epochs, ~25–40 minutes per trial), wasting hours of GPU compute on non-viable runs.
4. The study stopped early because `--study-patience 20` fired after 20 consecutive collapsed trials following Trial #8.

## Implementation Details
1. **Per-Trial Cryptographic Seed Randomization (`src/yoda/hyperopt/optuna.py`)**:
   - `run_training_trial`: If `"seed"` is not explicitly specified in `training_args`, automatically draws a cryptographically secure random integer (`secrets.randbits(31)`) strictly excluding 42.
   - Attaches `trial.set_user_attr("seed", trial_seed)` for provenance and audits in the database.
   - Forwards `--seed <val>` in the subprocess CLI execution command.
2. **Early Majority-Class Collapse Pruning (`src/yoda/training/trainer.py` & `experiments/train_yoda.py`)**:
   - Added `--collapse-threshold` (default 0.370) and `--collapse-patience-epochs` (default 2) to `YodaTrainer` and `train_yoda.py`.
   - In `YodaTrainer.fit`, after each validation epoch: if `epoch >= collapse_patience_epochs` and `eval_accuracy <= collapse_threshold`, training logs a warning and aborts immediately.
   - Reduces execution time of collapsed trials from ~30 minutes down to ~2–3 minutes.
3. **Focused Study Updates (`experiments/optuna_study_focused.py`)**:
   - Threaded `collapse_threshold` and `collapse_patience_epochs` through `build_base_study_parser` and `objective()`.
4. **Testing & Quality Assurance**:
   - Added unit tests in `tests/test_hyperopt.py` for parser collapse flags and trial seed injection.
   - Added unit tests in `tests/test_training.py` for CLI collapse arguments and `YodaTrainer` collapse early abortion.
   - Updated `tests/test_optuna_study_focused.py` mock assertions.
   - Verified 181/181 pytest tests pass and `ruff check .` passes cleanly.
