# Codebase Refactor: Submodule Reorganization, DLA Extraction to XAI, and Architecture Refinements

## Request
@[agents.md] Before we proceed further: some minor style issues.
1. Get rid of all the `from __future__ import annotations`, it's not 2018
2. `ltn.py` should probably be in the `nesy` submodule
3. `dataset.py` should probably be in the `data` subdirectory
4. The DLA components should probably be in the `xai` submodule rather than an ad-hoc function in an experiment script
5. The experimental logic MIGHT be cleaner if we used pytorch lightning (keyword: **might**). This would also allow us to get more integrated experiment tracking. We just need to make sure the final model isn't tied inseparably to lightning
6. Do we still need to unfreeze the final layer of the text embedding model? Maybe we'd be better off leaving it frozen now that we have a working model. (just a suggestion, i'm not entirely sure if this is a good idea)

## Plan
1. Remove all occurrences of `from __future__ import annotations` across `src/`, `tests/`, and `experiments/`.
2. Move `src/yoda/probabilistic/ltn.py` to `src/yoda/nesy/ltn.py`. Export in `src/yoda/nesy/__init__.py`. Provide backward-compatible import in `src/yoda/probabilistic/__init__.py`.
3. Move `src/yoda/training/dataset.py` to `src/yoda/data/dataset.py`. Export in `src/yoda/data/__init__.py`. Provide backward-compatible import in `src/yoda/training/__init__.py`.
4. Create `src/yoda/xai/dla.py` containing `run_dla_evaluation` and `format_dla_report`. Export in `src/yoda/xai/__init__.py`. Update `experiments/train_yoda.py` to import and call this submodule. Add dedicated tests in `tests/test_xai_dla.py`.
5. Document architectural analysis and recommendation for PyTorch Lightning integration (evaluating decoupling vs overhead, and optional `YodaLightningModule` adapter).
6. Evaluate freezing the text encoder's top layer vs fine-tuning, providing empirical and theoretical trade-offs.
7. Document ADR-0008 covering the submodule realignment.
8. Verify test suite with `uv run pytest` and linting with `just check`.

## Outcome

- Moved `src/yoda/training/dataset.py` to `src/yoda/data/dataset.py` and exported under `yoda.data`.
