# Request

Reorganize training pipeline in `experiments/train_yoda.py` to use a traditional 80/10/10 Train:Val:Test split on the primary dataset. Compute total length dynamically and slice into strictly non-overlapping train, eval, and test splits, removing hardcoded `--eval-path` offset carve-out logic.

## Reasoning

Previously, `experiments/train_yoda.py` loaded `--train-path` entirely for training, and carved out evaluation and test sets from `--eval-path` using hardcoded offsets (`offset=args.max_eval_samples` when `test_path == eval_path`). This led to potential data exhaustion or empty test splits when `--eval-path` contained fewer samples than the sum of eval and test limits, and failed to adhere to the standard 80/10/10 train/val/test machine learning split across the primary dataset.

Implementing a dynamic 80/10/10 split directly on the primary dataset (`--train-path`) ensures:
1. Strict partition non-overlap across training, validation, and held-out test splits.
2. Robust dynamic slice calculation regardless of dataset size (from tens to hundreds of thousands of samples).
3. Zero-copy columnar slicing directly on Polars DataFrames in `YodaParquetDataset`.
4. Graceful handling of single dataset workflows without relying on fragile multi-file offset assumptions.
