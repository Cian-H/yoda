## Implementation
- Diagnosed saturation dead-zone caused by `torch.clamp(base + delta, 0, 1)` in `BelnapTransformerBlock._residual_join`.
- Replaced hard clamping with a convex combination residual join: `res = (1.0 - alpha) * base + alpha * delta` (default `residual_weight=0.5`).
- Ensured output evidence strictly preserves $[0, 1]$ bounds while guaranteeing non-vanishing, linear gradient propagation $\frac{\partial \text{res}}{\partial \text{base}} = (1 - \alpha) = 0.5$.
- Added comprehensive unit tests in `tests/test_belnap_transformer.py` verifying gradient flow and boundedness under high base values.
- Documented in ADR-0007 (`0007-convex-combination-residual-joins.md`) and updated ADR index.
- Executed training run and DLA evaluation. Confirmed Stage 2 revival: marginal attribution rose from `+0.0000` to `+0.1117`, with monotonic target logit progression across stages (-1.7631 -> -1.6222 -> -1.5104) and healthy knowledge accumulation ($k = 0.3789 \to 0.3906 \to 0.3982$).
