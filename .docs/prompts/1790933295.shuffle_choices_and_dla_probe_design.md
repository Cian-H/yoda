# Request

Start with shuffling the options randomly to prevent the model from using the sequence as a shortcut, then design a careful, deliberate system for wiring up Direct Logit Attribution (DLA) probes. Commit the work done so far per team practices and wait for user input before continuing.

## Reasoning

When training multiple-choice models on synthetic datasets, models often develop positional shortcuts (such as always attending to the first option or preferring static choice positions) instead of evaluating semantic alignment. Dynamically permuting candidate options on each fetch guarantees that the model cannot memorize position heuristics and forces candidate-level evidence scoring. Concurrently, designing DLA probes provides mechanistic interpretability into whether each stage of the cascading reasoning core (Query -> State -> Constraints) actively contributes to decision resolution and uncertainty calibration.
