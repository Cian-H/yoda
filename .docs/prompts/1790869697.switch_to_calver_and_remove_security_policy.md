# Request

Switch project versioning to CalVer and remove application-centric security policies.

## Reasoning

The user noted that Yoda is a research model and experimental decision engine, not an application:
1. Semantic Versioning is a poor fit for research model iterations; Calendar Versioning (CalVer) `YYYY.MM.MICRO` reflects temporal development accurately.
2. Web/application vulnerability disclosure policies (`SECURITY.md`) and OWASP web methodology (`.docs/security/`) represent unnecessary ceremony for a non-service research codebase. Code-level safety (e.g. safetensors over pickle, secrets hygiene) is already codified in `best-practices.md`.

## Consulted rules

workflow.md — per-task prompt file and commit discipline
best-practices.md — model safety and serialization standards

## Output

- Switched `pyproject.toml` version to `2026.10.0` (CalVer `YYYY.MM.MICRO`).
- Updated `CHANGELOG.md` to declare Calendar Versioning (CalVer) and updated initial release to `[2026.10.0]`.
- Removed `SECURITY.md` and `.docs/security/methodology.md`.
- Removed `.agents/rules/workflow-security.md` and pruned references from `AGENTS.md` and `.agents/rules/workflow.md`.
