# Request

Add cleanly-licensed, schema-compatible Tier 1 datasets identified in the system-one census to Yoda's training corpus:
- `dwidlee/systemone-lite-phase2` (Apache-2.0, ~245k rows)
- `dwidlee/systemone-lite-general` (MIT, ~77k rows)
- `n4ze3m/typed-decisions-synth` (MIT, ~7.4k rows)
- `mghafiri/decision-model-scenarios` (MIT, ~2k rows)

Normalize all records to canonical `DecisionPayload` instances and aggregate into the training/evaluation dataset.

## Reasoning

Expanding Yoda's training dataset from the baseline ~11.7k rows to over 330k+ verified, cleanly-licensed (Apache-2.0 and MIT) records significantly bolsters the empirical breadth, domain coverage, and calibration robustness of the System 1 decision engine. These datasets follow the typed decision contract and require minimal restructuring into `DecisionPayload`.

## Consulted rules

- `.agents/rules/workflow.md` — per-task prompt file, commit discipline, and ADR creation
- `.agents/rules/workflow.md` §2 (ADR) — dataset architecture and schema alignment
- `.agents/rules/workflow-testing.md` — pytest unit testing for data ingestion and normalization pipeline
- `.agents/rules/best-practices.md` — Polars for tabular data and deterministic ordering

## Output

- Extended `DatasetIngestionPipeline` with parsers for `dwidlee` (Parquet tabular via Polars), `n4ze3m`, and `mghafiri` (JSONL).
- Ingested and transformed all candidate datasets into canonical `DecisionPayload` records.
- Produced expanded aggregated training and evaluation splits in `data/processed/`.
- Updated unit test suite in `tests/test_data_ingest.py`.
- Updated ADR 0003 with the extended corpus inventory.
