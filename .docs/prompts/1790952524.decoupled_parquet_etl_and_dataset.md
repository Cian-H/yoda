# Decoupled Parquet ETL and Dataset Pipeline

## Request
"Yes. Please implement it." (Decoupled Parquet ETL and dataset pipeline without embedding vectors baked into storage).

## Consulted rules
- `workflow.md`
- `agents.md`
- `best-practices.md`
- `workflow-testing.md`

## Plan
1. Create `src/yoda/data/etl.py`:
   - Extracts and standardizes JSONL records into structured tabular format using `polars`.
   - Pre-matches target labels to integer indices (`target_idx`).
   - Standardizes choices to fixed length `max_choices=5` with padding.
   - Maps `question_type` to continuous `task_scalar` (-1.0, 0.0, 1.0).
   - Writes clean, compressed Parquet files (`train.parquet`, `eval.parquet`).
2. Create `YodaParquetDataset` in `src/yoda/data/parquet_dataset.py` (or within `src/yoda/data/dataset.py`):
   - Reads directly from Parquet table via `polars`.
   - Supports in-memory fast indexing and on-the-fly candidate choice shuffling.
   - Decoupled from any embedding model: yields clean strings and integer labels.
3. Export new ETL and ParquetDataset classes in `src/yoda/data/__init__.py`.
4. Add CLI command or script `experiments/run_etl.py` to materialize the Parquet datasets.
5. Update `experiments/train_yoda.py` to seamlessly accept `--train-path` pointing to either `.parquet` or `.jsonl`.
6. Add unit tests in `tests/test_parquet_dataset.py`.
7. Document ADR 0010 on the decoupled columnar Parquet storage architecture.
8. Verify test suite and formatting via `just check`.

## Outcome
- Implemented `ParquetETLPipeline` in `src/yoda/data/etl.py` using `polars`.
- Implemented `YodaParquetDataset` in `src/yoda/data/parquet_dataset.py`, supporting fast columnar reading and on-the-fly candidate choice shuffling while keeping text embedding models completely decoupled.
- Created `experiments/run_etl.py` and executed the transformation:
  - `train.parquet`: 291,470 samples generated in 4.15s (16MB vs 280MB JSONL, 17.5× compression).
  - `eval.parquet`: 11,940 samples generated in 0.19s (1.1MB vs 16MB JSONL).
- Updated `experiments/train_yoda.py` to auto-detect `.parquet` inputs and added `--num-workers` and `--pin-memory` flags for DataLoader parallelism.
- Added comprehensive unit tests in `tests/test_parquet_dataset.py` (4 tests passing).
- Documented ADR 0010 (`.docs/adrs/0010-decoupled-columnar-parquet-dataset.md`) and updated index.
- Ran `just check`: all 92 tests pass cleanly with zero linter errors.
