# Cached run_etl Function

## Request
"Instead of this `run_etl.py` approach, we should just have a `run_etl` function, that skips if the cache is already populated with data that matches the call args."

## Consulted rules
- `workflow.md`
- `agents.md`
- `best-practices.md`
- `workflow-testing.md`

## Plan
1. Create `run_etl(...) -> Path` in `src/yoda/data/etl.py`:
   - Checks if target Parquet cache exists and matches calling arguments: `input_path`, input `mtime`, `max_choices`, `source`, `question_type`, `max_samples`.
   - Uses `.meta.json` sidecar metadata for deterministic fingerprint verification.
   - If valid, skips transformation and immediately returns cached Parquet path (`data.etl.cache_hit`).
   - If cache miss or invalidated, executes `ParquetETLPipeline.transform_jsonl_to_parquet`, updates metadata cache, and returns path.
2. Export `run_etl` in `src/yoda/data/__init__.py`.
3. Integrate `run_etl` into `experiments/train_yoda.py`:
   - When given a `.jsonl` path, automatically runs `run_etl` to get the cached `.parquet` representation transparently.
4. Update `experiments/run_etl.py` to be a thin CLI wrapper around `run_etl`.
5. Add unit tests in `tests/test_parquet_dataset.py` testing cache hits, cache invalidation on parameter change, and cache invalidation on input file update.
6. Verify test suite and formatting via `just check`.

## Outcome
- Implemented `run_etl(...) -> Path` in `src/yoda/data/etl.py` with argument matching, file modification timestamp (`mtime`) verification, and `.meta.json` sidecar caching.
- Exported `run_etl` in `src/yoda/data/__init__.py`.
- Integrated `run_etl` directly into `experiments/train_yoda.py`: if passed a `.jsonl` path, it automatically uses or creates the cached `.parquet` table.
- Updated `experiments/run_etl.py` to be a thin CLI wrapper around `run_etl`.
- Added unit tests in `tests/test_parquet_dataset.py` testing cache hits, parameter mismatches, input file modification invalidation, and missing files.
- Ran `just check`: all 93 unit tests passed with 0 linter errors.
