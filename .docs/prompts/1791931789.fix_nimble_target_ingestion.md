## Output

- Verified the bug empirically against the real raw corpus before coding: real Nimble records have no `teacher` block at all; gold decisions live under `reference.target` (a criteria key for choice questions, an integer ordinal for rubric/score questions), states are dialogue-event lists, and pairing is `variant` + `<pair_id>-base`/`-counterfactual` id suffixes.
- `DatasetIngestionPipeline.parse_nimble_record`: reads gold from `reference.target`; preserves `pair_id` and `variant` in payload metadata via a `_nimble_pair_key` helper (explicit `variant` field preferred, id-suffix fallback, unpaired ids tolerated).
- `match_target_to_constraints`: integer gold targets (JSON numbers — Nimble rubric/score rows, and the same encoding in kev and n4ze3m_synth) are now interpreted as ordinals into the constraint list; out-of-range returns None; booleans are explicitly excluded. This restored 6,335 previously dropped records across three sources, not just Nimble.
- ETL telemetry: `transform_jsonl_to_parquet` now counts skipped records per source (unmatched targets vs. targets beyond `max_choices`) and emits a `data.etl.records_skipped` warning — the silent skip that hid this bug class cannot recur invisibly.
- Regression tests: real-schema Nimble parsing (target from `reference.target`, dialogue-list state), pair metadata for base/counterfactual twins, null-target tolerance, ordinal integer matching (in-range, out-of-range, boolean exclusion). The fabricated `teacher.answers` mock was replaced with the real record shape.
- Re-ran ingestion and Parquet ETL locally (processed data is git-untracked): train corpus gains nimble 0 -> 2,617 rows, kev +488, n4ze3m_synth +4,848; eval gains nimble 308 (all), kev +203, n4ze3m +535. Remaining skips are now visible in telemetry: legitimate beyond-5-choice truncations, and records with empty constraint lists (no decision problem).
- Removed the superseded todo; added `.docs/todos/nimble-paired-contrastive-evaluation.md` capturing the remaining paired contrastive modeling scope (ETL pair columns, counterfactual consistency loss, flip metrics).
