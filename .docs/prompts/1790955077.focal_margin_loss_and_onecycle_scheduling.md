# Request

Implement Focal Loss and Margin Loss hybrid for decision ranking along with OneCycleLR learning rate scheduling, while keeping the multiplicative LTN constraint penalty.

## Reasoning

The previous test run demonstrated plateauing loss and accuracy stagnation (~35%). Standard Cross-Entropy forces bounded epistemic states ($t, k \in [0, 1]$) towards infinity, saturating sigmoids, while failing to downweight easy negatives (padded or irrelevant options). A hybrid of Categorical Focal Loss (downweighting easy negatives) and Margin Ranking Loss (enforcing robust separation between target and competing choices without infinite saturation), combined with OneCycleLR annealing (dynamic LR and momentum warmup/cooldown), stabilizes optimization while preserving multiplicative LTN constraints against reward hacking.
