# Request

Implement Belnap Multihead Pooled Attention (`BelnapMultiheadPooledAttention`) combining multihead cross-attention query pooling with four-valued Belnap bilattice logic, supporting zero-knowledge suppression, contradiction preservation, and decoupled decision context aggregation.

## Reasoning

Standard `MultiheadPooledAttention` utilizes softmax attention, which forces 100% mass allocation over vacuous or missing input tokens (causing attention sinks and hallucinations) and algebraically cancels opposing evidence (+v and -v) into false neutral vectors. A Belnap Bilattice Native MPA uses learnable epistemic query probes ($Q^+, Q^-$) and bipolar cross-attention gated by source knowledge ($k_{\text{src}}$) to pool variable-length constraints, rules, and symbolic facts into fixed-dimensional representations while preserving exact truth, knowledge, and contradiction invariants.
