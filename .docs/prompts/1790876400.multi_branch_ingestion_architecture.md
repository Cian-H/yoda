# Request

Design model architecture with specialized, decoupled ingestion pathways for each component of the `DecisionPayload` schema (`query`, `context` [semantic_embedding, symbolic_state, history], `constraints`, `metadata`) rather than a monolithic JSON string transformer.

## Reasoning

Treating structured decision payloads as flat JSON text in an autoregressive or standard encoder transformer incurs massive latency overhead, wastes compute on syntactic punctuation, and destroys semantic and logical invariants. A decoupled multi-branch architecture processes each data modality with tailored encoders:
1. Dense query text projection for intent.
2. Symbolic state & facts encoder with structured pooling (`MultiheadPooledAttention`).
3. Set-based constraint / candidate representations grounded by neuro-symbolic invariants (`BelnapBilattice`).
4. Low-latency cross-attention fusion producing calibrated discrete choices, scores, or noul decisions in under 10ms.
