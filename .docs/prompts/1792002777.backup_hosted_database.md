# Request

The user requested backing up the hosted Neon PostgreSQL database to the local
repository, removing the obsolete legacy database files (`data/optuna.db`,
`data/optuna_narrow.db`, and their metadata JSONs), and committing the changes
to git so the temporary hosted database can be safely torn down before going on
leave.

## Reasoning

The distributed hyperparameter optimization runs used a hosted Neon Postgres
database instance (`postgresql+psycopg://...`) across multiple remote worker
nodes. With the v2 hyperparameter optimization runs complete (including sanity,
broad, focused, and validate phases), the hosted database needs to be decommissioned.

To retain complete offline reproducibility without keeping live cloud infrastructure
or credentials running, all studies and trials from the hosted database were
migrated into a local SQLite database (`data/optuna_v2.db`) and a portable,
credential-free JSON archive (`data/optuna_v2_backup.json`). The legacy pre-M4
database files are purged to avoid confusion with the hardened architecture.
